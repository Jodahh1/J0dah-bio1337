# JODAH — сайт

Статический сайт: главная (bio), 3 игры («Игры»), скрытая админ-панель. Готов к деплою на Vercel как есть — без сборки, без бэкенда.

Стиль: чистый и спокойный тёмный фон (не чёрный, тёплый графит), один яркий акцент — градиент фиолетовый→коралловый на главной кнопке, шрифты Fraunces (для имени и цитаты) + Manrope (для всего остального). Без шума, без гуля, без резких углов — просто аккуратные карточки. Функциональность (игры, вход в админку, редактирование bio) не менялась.

## Деплой на Vercel

**Вариант 1 — без Git:**
1. Зайди на vercel.com → Add New → Project → «Deploy without Git».
2. Перетащи всю папку с файлами (или zip, который распакуй перед загрузкой).
3. Vercel сам определит, что это статика (Other / Static). Framework Preset можно оставить пустым.

**Вариант 2 — через GitHub:**
1. Залей файлы в новый репозиторий.
2. На vercel.com → Add New → Project → выбери репозиторий → Deploy.

Никаких переменных окружения и настроек сборки не нужно.

## Структура

- `index.html` — главная страница с bio
- `games.html` — список игр
- `game-2048.html` / `game-snake.html` / `game-tictactoe.html` — игры
- `admin.html` — админ-панель (доступ только после входа)
- `style.css` — общий стиль (стекло/glassmorphism)
- `main.js` — логика главной страницы + секретный вход
- `admin.js` — логика админ-панели

## Как открыть админку

На главной странице **одновременно зажми и удерживай ~1 секунду** клавиши **J + D + H**. Появится окно входа.

Логин по умолчанию:
- **Логин:** `jodah`
- **Пароль:** `jodah-tyumen-16`

Поменять их можно в файле `main.js`, в самом верху — там есть строки:
```js
const ADMIN_USER = 'jodah';
const ADMIN_PASS = 'jodah-tyumen-16';
```

⚠️ Важно: это чисто клиентская защита «для вида» — сайт статический, без сервера, и пароль лежит прямо в JS-коде, так что любой, кто откроет исходный код страницы, сможет его увидеть. Для настоящей защиты нужен бэкенд (например, Vercel Serverless Function + переменные окружения) — если понадобится, могу помочь это добавить отдельно.

## Что умеет админка

- Показывает счётчик визитов и рекорды в играх (2048, змейка) — они хранятся в `localStorage` **этого же браузера**, то есть не общие для всех посетителей.
- Позволяет менять текст на главной (имя, город, возраст, цитату и т.д.) — изменения тоже сохраняются в `localStorage` и видны только в этом браузере/устройстве. Если нужно, чтобы правки видели все посетители сайта, нужна база данных на бэкенде.
